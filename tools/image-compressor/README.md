# Image Compressor Tool

A client-side image compression tool that supports JPG, PNG, and WebP formats.

## Features
- **Auto & Manual Modes**: Choose between best balance or custom quality.
- **Batch Processing**: Compress multiple images at once.
- **Privacy First**: All compression happens in the browser; no images are uploaded to a server.
- **Formats**: Supports JPG, PNG, WebP.

## Structure
- `ui/`: UI rendering and updates.
- `logic/`: Compression logic and event handlers.
- `state/`: Application state management.
- `styles/`: CSS styles.
- `utils/`: Analytics and helpers.

## Usage
1. Drag & drop images or click "Select Images".
2. Adjust settings if needed.
3. Click "Compress All".
4. Download individual images or a ZIP of all images.
