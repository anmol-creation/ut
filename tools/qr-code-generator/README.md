# QR Code Generator

## Description
A simple tool to generate QR codes for URLs, text, email, phone, SMS, and Wi-Fi credentials. Also includes a scanner feature.

## Structure
- `index.html`: Main entry point.
- `ui/`: UI logic.
- `logic/`: Core logic for generation and scanning.
- `styles/`: Custom CSS.

## Usage
Select the input type, enter data, and click "Generate".
To scan, switch to the "Scan" tab.

## Libraries
- `qrcode.js` (via CDN) for generation.
- `html5-qrcode` (via CDN) for scanning.
